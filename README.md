## Featured Projects

### ☁️ <a href="https://github.com/Jaivinay/cloud-data-pipeline-using-aws-snowflake">AWS &amp; Snowflake Data Pipeline</a>

<p>
<strong>Problem:</strong> Raw e-commerce data needs a reliable path from source to analytics-ready warehouse tables.<br>
<strong>Implementation:</strong> S3 → AWS Glue (PySpark) transform into a star schema → 9 automated data-quality checks → Snowflake load via idempotent MERGE. The transform logic and ingestion flow are tested locally (mocked S3 via <code>moto</code>, 7 passing PySpark tests); the Glue job is written and packaged for AWS deployment but has not been run against a live AWS account.<br>
<strong>Tech:</strong> AWS S3 · AWS Glue · PySpark · Snowflake · pytest · GitHub Actions CI
</p>

### 📈 <a href="https://github.com/Jaivinay/AI-Driven-Demand-Forecasting">AI-Driven Demand Forecasting</a>

<p>
<strong>Problem:</strong> Multi-store, multi-SKU retail pricing needs a demand forecast it can trust before optimizing on top of it.<br>
<strong>Implementation:</strong> A Temporal Fusion Transformer forecasts demand across the Walmart M5 dataset (30,000+ SKUs); a PPO reinforcement-learning agent then recommends pricing on top of that forecast, producing a reported ~25% improvement in pricing efficiency in the project's own evaluation.<br>
<strong>Tech:</strong> PyTorch · Temporal Fusion Transformer · PPO / Reinforcement Learning
</p>
